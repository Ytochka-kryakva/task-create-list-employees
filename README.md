# Веб-приложение «Список сотрудников»

## Описание

Веб-приложение для управления списком сотрудников с авторизацией, поиском и фильтрацией.

## Стек

- **Frontend:** React 19 + TypeScript + Vite + обычный CSS
- **Backend:** Node.js + Express + TypeScript
- **База данных:** SQLite

## Требования

- Node.js 18+
- npm

## Установка

### 1. Бэкенд

```powershell
cd backend
npm install
```

Скопируйте `.env.example` в `.env` и при необходимости измените настройки:

```powershell
copy .env.example .env
```

### 2. Фронтенд

```powershell
cd frontend
npm install
```

Скопируйте `.env.example` в `.env` и при необходимости измените настройки:

```powershell
copy .env.example .env
```

## Запуск

### 1. Бэкенд

```powershell
cd backend
npm run dev
```

Сервер запустится на `http://localhost:3001`

### 2. Фронтенд

```powershell
cd frontend
npm run dev
```

Приложение откроется на `http://localhost:5173`

## Функционал

- Регистрация по email и паролю
- Вход и выход
- Список сотрудников (только после авторизации)
- Поиск по ФИО
- Фильтр по отделу
- Добавление сотрудника через форму с валидацией
- Данные сохраняются после перезапуска (SQLite)
